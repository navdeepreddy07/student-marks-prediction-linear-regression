# Student Marks Prediction Using Linear Regression

A beginner-friendly Machine Learning project that predicts student marks based on study hours using Linear Regression, Scikit-learn, and Matplotlib.

## About
This project predicts student marks based on the number of hours they study using a Linear Regression model.

## Technologies Used
- Python
- NumPy
- Matplotlib
- Scikit-learn
- Jupyter Notebook

## What I Learned
- Preparing input features and target values
- Splitting data into training and testing sets
- Training a Linear Regression model
- Predicting marks for a new student
- Evaluating the model using MAE, MSE, and RMSE
- Visualizing actual data and the regression line

## Project Type
Beginner Machine Learning Project
